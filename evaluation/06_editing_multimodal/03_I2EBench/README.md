# I²EBench / I2EBench

## 一句话介绍

面向指令图像编辑的多维基准，包含 2,000+ 张图、4,000+ 条原始及多样化指令，以 16 个高低层维度和人工排序验证模型能力及指令改写稳健性。

- **规模**：2,000+ 输入图、4,000+ 指令
- **维度**：16 个，覆盖高层编辑和低层复原/细节处理
- **评分**：部分用 CLIP 等传统指标，部分用带人工标准 QA 的 GPT-4V
- **补充**：人工排序用于检验自动分与人类感知的一致性

## 评价维度

低层部分包括 deblurring、haze removal、low-light enhancement、noise/rain/shadow/snow/watermark removal 等；高层部分覆盖对象增删改、数量、位置、属性、背景和风格等指令编辑。应按官方 16 列完整报告，不宜只选模型擅长的几项。

## 自动评分流程

1. 原始指令与同义/多样化指令分别生成结果。
2. 风格等维度可使用 CLIPScore。
3. 对需视觉验证的维度，人工预先写问题及标准答案。例如“在鞋架上加一只猫”对应“鞋架上有几只猫？”、“一只”。
4. GPT-4V 看图回答，按标准答案和官方脚本转为该维分。
5. 每维聚合，并按 animal/object/scenery/plant/human/global 等内容类别切片。

## I²EBench Change Rate

衡量原指令得分 `S_o^i` 与多样化指令得分 `S_d^i` 的相对变化：

`ChangeRate_i = |S_o^i - S_d^i| / min(S_o^i, S_d^i)`

越低表示对指令改写越稳健。该比值在分母接近 0 时极不稳定，应设数值阈值并同时报告两个原始分；不同维度量纲需一致后再比较。

## 人工对齐验证

人工看到输入图、指令和多模型结果并排序。若共 M 个模型，排第 k 得 `M-k+1`，再求每维均值。自动分也转换为相同排名分后与人工作相关分析。它验证的是**该模型集合内的排序一致性**，不自动保证对新模型仍可靠。

## 优点

- 高低层覆盖广，能区分通用指令编辑与复原型编辑。
- 原始/多样指令提供鲁棒性检查，而非只测单一模板。
- 提供人工 QA、人工排序和多模型输出，便于审查 judge。

## 局限

- 16 维使用的评分器与尺度不同，整体平均需谨慎。
- GPT-4V 自由回答与标准答案匹配有语言和模型误差。
- 早期基准对复杂多模态、多轮和真实开放指令覆盖有限。
- Change Rate 对低分样本非常敏感，不能只报百分比。

## 版本提醒

原版论文为 2024 年；后续 I2EBench 2.0 扩展到单轮和多轮编辑。引用时必须注明版本，不能把新增多轮维度混入原 16 维结果。
