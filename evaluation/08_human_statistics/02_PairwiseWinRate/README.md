# Pairwise Win Rate（成对胜率）

## 一句话介绍

同一 prompt/输入下将两模型输出匿名并排，让人或 VLM 选 A、B 或平局，再统计胜率；是模型相对比较最直观的人工评价方式。

- **输入**：配对的 A/B 输出、相同条件、评审者选择
- **输出**：A 胜/B 胜/平局比例及置信区间
- **适用**：文生图、编辑、主体保持、整体偏好
- **不是**：跨不同对手池仍恒定的绝对质量分

## 两种常见口径

### 平局计半（推荐同时报告）

`WR_A = (W_A + 0.5*T) / (W_A+W_B+T)`

因此无平局时 `WR_A+WR_B=1`；有平局时两者也互补。

### 只统计非平局

`WR_A(decisive) = W_A/(W_A+W_B)`

另报 `tie_rate=T/(W_A+W_B+T)`。只报“胜率 70%”却不写平局处理，结论可能完全不同。

也可报告 **net win rate**：`(W_A-W_B)/N`，范围 -1 到 1。

## 实验设计

1. 对同一 prompt、尽可能相同推理预算和输出尺寸生成 A/B。
2. 随机交换左右位置，隐藏模型名；同一评审者可做位置平衡而不是重复同图刷票。
3. 允许多个维度分别比较：对齐、画质、主体保持、整体。整体问题要明确主要业务目标。
4. 允许 tie 和“无法判断”，后者单独计，不强迫变成偏好。
5. 记录评审者、prompt、模型版本与时间；失败/拒答输出作为预先定义的一类结果。

## 统计

简单比例区间只是起点。若同一 prompt 有多对输出、同一标注者有多票，观测并不独立。建议：

- 以 prompt 为聚类单位 bootstrap；多评审者时做 prompt/rater 多层或聚类处理；
- 报告有效票数、独立 prompt 数、评审者数、tie 率与 95% CI；
- 对 A-B 差值做配对检验，不把重叠的模型平均分区间当成唯一显著性依据。

## 优点

- 相比绝对 MOS 更容易做选择，跨批次校准压力小。
- 直接回答“同任务哪个模型更好”，与产品体验接近。
- 可得到两两矩阵，进一步拟合 Bradley–Terry/Elo。

## 局限

- 胜率依赖对手、prompt 分布、投票人群和评判维度。
- 位置偏差、审美偏差、图像顺序、品牌猜测都可能影响结果。
- 总体胜率可能掩盖关键子类严重失败，应分层报告。
- VLM 作为投票者时不是人工胜率，必须标明 judge 并做人机一致性校验。
