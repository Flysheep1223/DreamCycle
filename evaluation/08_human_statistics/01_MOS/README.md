# MOS / DMOS（Mean Opinion Score）

## 一句话介绍

让多位标注者按统一量表给图像质量、对齐或偏好打分，再取平均得到 MOS；DMOS 是相对于参考/失真的差分意见分，常用于质量评价。

- **输入**：每张图多位标注者的 1–5、0–10 等评分
- **输出**：量表内均值，越高还是越低取决于 rubric
- **核心**：题意、锚点、随机顺序、标注者数量、置信区间
- **注意**：不同研究的 MOS 通常不能直接横比

## 计算

第 `i` 张图有 `R_i` 个有效评分 `r_ij`：

`MOS_i = (1/R_i) Σ_j r_ij`

数据集的模型分可对图像 MOS 再平均，或在每个 prompt/类别内先平均后宏平均。若每位标注者看到的图像数不同，直接把所有评分混合会让样本/标注者权重不均衡。

DMOS 的具体方向取决于定义：某些 IQA 协议用参考质量减失真质量，越高越差；另一些研究自行定义差分。因此使用 DMOS 必须给公式，不能默认与 MOS 同向。

## 量表设计

- 对齐：1 完全不匹配，2 重大差异，3 多个小差异，4 少量小差异，5 完全匹配。
- 感知质量：明确是否评价真实感、伪影、清晰度、构图，避免一个问题混合多个轴。
- 编辑：分别问指令完成和未编辑内容保持，不能只问“好不好”。
- 给每级图像锚点和边界案例，先做 pilot，再冻结 rubric。

## 优点

- 可直接对应明确的人类判断，适合构建自动指标验证集。
- 每图绝对分可用于 SRCC/PLCC、回归和阈值化可用率。
- 多标注者可估计分歧和不确定性。

## 局限

- Likert 等级是有序类别，严格说不保证相邻等级等距；均值是常见实用近似。
- 量表压缩、标注者严格程度、上下文和疲劳会改变分数。
- 绝对评分跨批次校准困难；模型排序最好再用成对盲测验证。
- 单个总体 MOS 会掩盖人群、风格、文化与业务场景差异。
- 不应只报告均值而不报告评分人数、分歧、样本量和区间。

## 推荐报告

每图至少多位独立标注者；随机去模型名；保存原始评分而非只存均值；报告 `MOS±95%CI`、评分分布、标注者一致性及筛除规则。自动指标验证时使用独立 held-out 图像，避免训练/验证泄漏。
