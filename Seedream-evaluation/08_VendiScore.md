# 多样性：同 Prompt 组内 Vendi Score

## 1. 这个维度测什么？

当用户对同一 prompt 多次点击生成时，希望看到不同但有价值的方案，而不是：

- 四张几乎一样；
- 四张都随机偏离 prompt；
- 只改变无关噪声；
- 一张正确，另外三张完全不可用。

Vendi Score 用一组图像的相似度矩阵估计“有效不同元素数量”。对文生图，最有意义的用法是：**同一 prompt 的多 seed 组内多样性**。

## 2. 公式与直观解释

对 `n` 张图构造半正定相似度矩阵 `K`，令 `K/n` 的特征值为 `λ_i`：

`VS = exp(-Σ_i λ_i log λ_i)`

- 所有图几乎相同：VS 接近 1；
- 有 2 类有效不同图像：VS 接近 2；
- 4 张图都彼此不同：VS 接近 4。

分数上界受组内图像数 `n` 限制，所以 4 图组和 8 图组的原始 VS 不应直接比较。

## 3. 三个简单例子

假设每个 prompt 都生成 4 张图。

### 情况 A：四张几乎复制

```text
[A, A, A, A]
```

相似度矩阵近似全 1，只有一个主要方向，`VS≈1`。

### 情况 B：两种构图，各重复两次

```text
[A, A, B, B]
```

有两个有效方向，`VS≈2`。

### 情况 C：四种不同但合理的方案

```text
[室内近景, 室外全景, 水彩风格, 低角度构图]
```

若相似度定义认为它们彼此独立，`VS≈4`。

这些数值是理想化演示。真实结果取决于 CLIP、DINO、DreamSim 等相似度 backbone。

## 4. 关键反例：坏图也能增加多样性

Prompt：

> 一只橘猫坐在窗边看书。

四张输出：

1. 橘猫在室内窗边看书；
2. 橘猫在阳台看书；
3. 水彩风橘猫在窗边看书；
4. 一只狗在操场上踢球。

第 4 张显然不同，会提高组内多样性，但完全不符合 prompt。因此应同时报告：

- `VS`：组内有效差异；
- `VQAScore/Soft-TIFA`：语义成功率；
- `Q-Align/人工 PQ`：基本可用性。

可以在全部样本上计算 VS，但**不能将高 VS 单独解释为优点**。若只在语义合格样本上算，还要同时报告合格样本数，避免选择性删除。

## 5. 聚合例子

两个 prompt 各生成 4 图：

| Prompt | VS | 语义成功率 |
|---|---:|---:|
| P1 | 2.8 | 0.90 |
| P2 | 1.6 | 0.85 |

组内宏平均：

- 平均 VS=`(2.8+1.6)/2=2.2`；
- 平均语义成功率=`(0.90+0.85)/2=0.875`。

不要把两个 prompt 的 8 张图混在一起算一个 VS，因为不同 prompt 本来就应该不同，这不能证明采样多样性。

## 6. 推荐报告

- 相似度模型及精确 checkpoint；
- 每 prompt 图像数 K；
- 每 prompt VS 后取宏平均；
- 语义成功率和画质；
- 不同 prompt 间的全局 VS 如需报告，单独命名，不能与组内 VS 混用。
