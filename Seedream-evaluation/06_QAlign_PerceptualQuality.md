# 感知画质：Q-Align / OneAlign + 人工质量检查

## 1. 这个维度测什么？

感知画质关心“这张图本身是否自然、清晰、可用”，例如：

- 是否有模糊、噪声、过曝和压缩感；
- 人物手部、牙齿、眼睛和肢体是否异常；
- 物体结构是否破碎或融化；
- 局部拼接是否自然；
- 画面是否充满生成式伪影。

它与文图对齐不同：**一张很漂亮但没有按 prompt 画的图，可以画质高、对齐低。**

## 2. Q-Align 的五级评分

Q-Align 让多模态模型在五个等级上输出概率：

- excellent → 5
- good → 4
- fair → 3
- poor → 2
- bad → 1

再加权得到 1–5 的连续分。

`Score = 5p_excellent + 4p_good + 3p_fair + 2p_poor + 1p_bad`

## 3. 数值例子

假设某图的概率为：

| 等级 | 概率 |
|---|---:|
| excellent | 0.10 |
| good | 0.20 |
| fair | 0.40 |
| poor | 0.20 |
| bad | 0.10 |

则：

`Score = 5×0.10 + 4×0.20 + 3×0.40 + 2×0.20 + 1×0.10 = 3.00`

另一张图概率为 `[0.60,0.20,0.10,0.05,0.05]`：

`Score = 5×0.60 + 4×0.20 + 3×0.10 + 2×0.05 + 1×0.05 = 4.25`

加权分保留了“可能在 good 与 fair 之间”的连续性，比只取最大概率等级更细。

## 4. 一个必须同时看对齐的反例

Prompt：

> 一只戴红色帽子、坐在蓝色椅子上的猫。

- 图 A：猫、帽子、椅子及颜色都正确，但猫爪有明显结构异常。
- 图 B：一张摄影感很强的普通猫照片，没有红帽子和蓝椅子，细节自然。

可能得到：

| 图像 | 语义对齐 | Q-Align 画质 | 应如何解释 |
|---|---:|---:|---|
| A | 高 | 较低 | 听懂了，但局部质量影响可用性 |
| B | 低 | 高 | 画质好，却没有完成任务 |

若只按 Q-Align 排名，B 可能获胜；若只按语义排名，A 的伪影又会被忽略。正确做法是保留两个维度，并在人工整体偏好中检验实际权衡。

## 5. 人工质量 rubric 示例

可以让评审者独立按 1–5 评感知质量：

| 分数 | 参考标准 |
|---|---|
| 5 | 无明显结构错误和伪影，可直接使用 |
| 4 | 有轻微问题，但不影响主要内容和一般使用 |
| 3 | 有可见伪影或局部不自然，需要修图 |
| 2 | 多处明显结构问题，严重影响使用 |
| 1 | 图像破碎、主体不可辨或完全不可用 |

同时允许勾选问题类型：手部、脸部、肢体、物体结构、文字外区域、背景、清晰度、色彩、其他。这样比只有一个 MOS 更容易指导模型改进。

## 6. 其他指标放在哪里？

- **Aesthetic Predictor**：衡量美学倾向，可作为辅助，不等同技术画质。
- **CLIP-IQA**：快速评估 quality/sharpness 等语义属性，容易受 CLIP 和提示词影响。
- **MUSIQ**：自然图像无参考质量基线，需注明 checkpoint；对生成式语义幻觉没有保证。
- **HPS/PickScore**：综合偏好，不是纯画质分。

## 7. 常见误用

- 把 Q-Align 的 4.2 当成 84% 人满意。
- 不同 Q-Align/OneAlign 版本直接比较原始分。
- 用自然度指标统一惩罚插画、水彩等合理非写实风格。
- 只报平均画质，不检查低分尾部分布和关键人物伪影。
- 让“美”掩盖“没按 prompt 画”。
