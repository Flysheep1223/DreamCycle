# 多路机评结果：只保留分离指标

> 不再推荐把 VLM、OCR、编辑、参考图等结果归一化后合成一个总分。不同指标的输入、量纲和误差来源不同，目前没有足够可靠的统一归一化方法。旧版自定义 Overall/权重方案已弃用。

## 为什么不做总分？

1. **量纲不同**：SC/PQ 是 0–10，CP/PF 是 0–4，OCR Accuracy 是 0–1，CER 是错误率，LPIPS 是距离。
2. **任务不同**：文字正确不代表语义完成，主体保持不代表未编辑区域保持，画质高也不代表指令完成。
3. **误差不同**：OCR 误识别、VLM 误判和检测器漏检不能用统一概率解释。
4. **权重会掩盖失败**：一项高分可能掩盖另一项关键失败，归一化后的 0.8 不具备统一的“80% 可用”含义。

## 各指标如何使用？

| 指标 | 原始尺度 | 回答的问题 |
|---|---|---|
| Task score | 0–1 | 指令中的任务条件完成了多少？ |
| Preservation score | 0–1 | 应保持的内容保留了多少？ |
| PQ | 0–10 | 图像是否自然、少伪影？ |
| 编辑 SC / PQ | 各 0–10 | 编辑语义和感知质量分别如何？ |
| 参考图 CP / PF | 各 0–4 | 主体保持和新 Prompt 遵循分别如何？ |
| OCR Accuracy | 0–1 | 目标文字有多少完全正确？ |
| NED / CER / F1 | 各自定义 | 文字相似度、错误率和检出完整性分别如何？ |
| 全项通过率 | 0–1 | 检查项中达到严格通过阈值的比例，不是综合质量分 |

## 不适用项

不适用项使用 `null`，不要记 0，也不要为了统一格式强行补值。例如纯文生图没有背景保持分，单张图不能计算 Vendi 或 FID。

## 阅读原则

- 先看任务相关指标，再看逐项失败原因；
- 不把 OCR Accuracy 当作文字排版正确率；
- 不把 CP 高理解为 PF 也高；
- 不把 PQ 高理解为任务完成；
- 不用不同指标的数值大小直接比较模型优劣，应分别比较同一指标在相同协议下的变化。
