# 评测协议：先把“怎么比”固定下来

## 1. 推荐测试集组合

### 公共集：保证可比性

- **GenEval 2**：800 条，测组合原子及联合满足。
- **DPG-Bench**：1,065 条，测长、稠密 prompt。
- **GenAI-Bench**：1,600 条，测真实设计型组合 prompt，可用 VQAScore。
- **AnyText / CVTG-2K**：测中英文字、多区域文字。
- 按能力增加 WISE、GEdit、PIE、DreamBench++、MMIG。

### 私有集：保证与真实业务相关

建议准备 **300–500 条 prompt**，不要从公开 benchmark 简单改写。一个可用于起步的结构示例：

| 类型 | 示例 | 建议覆盖 |
|---|---|---|
| 基础主体与场景 | “清晨雾气中的江南水乡，一艘空木船” | 常规画质与语义 |
| 属性绑定 | “红色杯子在蓝盘子上，黄色杯子在绿盘子上” | 防止颜色串换 |
| 数量 | “三只猫，两只坐着，一只躺着” | 总数与分项数量 |
| 空间关系 | “小椅子在大桌子左边，但在台灯右边” | 多关系联合满足 |
| 长而稠密 | 指定人物、服装、动作、背景、天气、镜头、文字 | 漏项检查 |
| 否定与排除 | “房间里有一张空桌子，桌上不要出现杯子” | 非模板能力；需单独验证 judge |
| 中文与多语言 | 中文招牌、中英混排、文化实体 | 不只测试英文翻译 |
| 文字与版式 | 海报标题、价格、日期、按钮文案 | OCR 和布局分别评分 |
| 知识与推理 | “适合在冬至吃的传统食物” | 隐含知识 |
| 失败回归 | 历史版本曾经出错的 prompt | 防止旧问题复发 |

比例按业务分布确定，不要为了凑总分随意等权。保留每条 prompt 的类型标签，便于宏平均和切片。

## 2. 生成设置

### 自动评测

- 推荐每 prompt **4 个固定 seed**，全部计分，估计单次生成的期望表现。
- 相同模型对比使用同一组 seed；不同模型不必强求相同 latent，但 seed 列表和生成规则要一致。
- 固定分辨率、长宽比、采样步数、guidance、negative prompt、refiner/超分和后处理。
- 若模型提供 prompt 自动改写，分别跑：
  - `raw prompt`：用户原文直接输入；
  - `system prompt enhancement`：实际产品完整管线。
  保存改写后文本，两者不能混为一个结果。

### 人工评测

- 不要为了人工展示从 4 张里挑最好的一张，除非研究目标就是 `best-of-4 + 选择器`。
- 常规单样本体验：用预先指定的 seed，例如每 prompt 第 1 个。
- 如果比较 best-of-N，所有模型都必须有相同 N 和同等选择预算，并明确选择器。

## 3. 评价范围：只看生成效果

本目录只评价输出图像的效果，包括语义对齐、组合能力、文字渲染、感知画质、编辑效果、参考图一致性和人工偏好。服务与工程因素不纳入评分。

所有模型应在同一批测试样本上评分，报告相同的 prompt 集合、生成配置和样本范围。样本划分应预先确定，不根据模型表现临时调整。

## 4. 固定自动评审器

- VQAScore：记录 VLM、checkpoint、question template、token 概率提取方式。
- Soft-TIFA：记录 GenEval 2 数据版本、VQA 模型、AM/GM。
- DPG：记录 mPLUG 版本和官方代码 commit。
- GEdit/VIEScore：记录 judge 快照、完整提示词、temperature、输入图像尺寸；保留原始回复。
- OCR：记录检测与识别模型、语言、置信度、框匹配和文本归一化。

商业 judge 更新后不要直接拼接新旧结果。开放 judge 也要记录精确 revision，而不是只写“Qwen”。

## 5. 聚合和区间

- 先算每图分，再按 prompt、任务类别聚合；说明是图像微平均还是类别宏平均。
- 多问题 prompt 应整块处理，避免长 prompt 因问题多而权重过大。
- 对同一 prompt 的多图、多问题，以 **prompt 为单位做聚类 bootstrap**，给 95% CI。
- 两模型比较尽量使用同 prompt 的配对差值，而不是只比较两个独立均值。
- 同时报有效样本数、失败数和最佳单张/全部图平均的口径。

## 6. 推荐逐样本数据结构

```json
{
  "prompt_id": "private_0001",
  "prompt": "红色杯子在蓝盘子上，旁边有三只黄色铅笔",
  "tags": ["attribute_binding", "counting", "spatial"],
  "model": "model-name-and-exact-version",
  "run_date": "YYYY-MM-DD",
  "seed": 0,
  "image_path": "images/private_0001/0.png",
  "soft_tifa": {"AM": 0.82, "GM": 0.71},
  "vqascore": 0.76,
  "ocr": {"accuracy": 1.0, "ned": 1.0, "cer": 0.0},
  "judge_versions": {"vqa": "exact-checkpoint", "ocr": "exact-version"}
}
```

字段名可调整，但要能由逐样本文件重新算出总表。

## 7. 最容易破坏结论的行为

- 给不同模型使用不同 prompt 改写强度；
- 只展示最好 seed；
- 某模型生成 4 张选 1 张，另一个只生成 1 张；
- 不同模型使用不同测试 prompt 或样本范围；
- 换 VLM judge 后仍沿用旧阈值或旧排行榜；
- 把 OCR 未检出样本从平均分中剔除；
- 在公开测试集上反复调 prompt，再称其为 held-out 结果。
