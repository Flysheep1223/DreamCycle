# 综合人类偏好：成对盲测胜率 + HPS v3 辅助

## 1. 为什么最终需要人工成对比较？

自动指标可能分别偏爱：

- 语义更准确但画面保守的模型；
- 画面漂亮但漏条件的模型；
- 与某个奖励模型训练风格接近的模型。

真实产品往往关心“同一需求下，用户更愿意用哪张图”。成对盲测直接回答这个问题，是 Seedream 类模型最终排名中最重要的校验手段之一。

## 2. 成对盲测怎么做？

对同一条 prompt，将模型 A、B 的输出匿名并排：

- 随机交换左右位置；
- 隐藏模型名称；
- 相同输出尺寸和生成预算；
- 评审者可选择 A、B、平局、无法判断；
- 对齐、画质、整体偏好最好分成不同问题，避免题意混杂。

### 推荐评审问题

**整体偏好**：

> 假设这是你的真实需求，你更愿意使用哪张图？请综合考虑指令完成、视觉质量和可直接使用程度。

需要诊断时再分别问：

- 哪张更完整地遵循 prompt？
- 哪张视觉质量更高、伪影更少？
- 哪张更适合直接交付？

## 3. 胜率计算例子

假设在 100 个独立 prompt 上比较 A 与 B：

- A 胜 45；
- B 胜 35；
- 平局 20。

### 平局计半胜率

`WR_A = (45 + 0.5×20)/100 = 55%`

`WR_B = (35 + 0.5×20)/100 = 45%`

### 只统计非平局

`WR_A(decisive) = 45/(45+35) = 56.25%`

### 其他必须报告的量

- 平局率：20%；
- 净胜率：`(45-35)/100 = 10%`；
- 有效 prompt 数、投票人数；
- 按 prompt 聚类 bootstrap 的 95% CI。

如果只写“A 胜率 56.25%”，读者可能不知道你忽略了平局，因此两种口径应同时给。

## 4. HPS v3 是什么、怎么用？

HPS v3 是基于 Qwen2-VL 的偏好模型，在 HPD v3 上训练。输入 prompt 和图像，输出偏好均值 `μ`，并有能力表示不确定性。

假设同一 prompt 三张图：

| 候选 | HPS v3 μ（虚构示例） | 可用方式 |
|---|---:|---|
| A | 10.4 | 同 prompt 下排名第一 |
| B | 10.1 | 排名第二 |
| C | 9.8 | 排名第三 |

这些数值**不是十分制用户评分，也不是“10.4 人中有 10.4 人喜欢”**。它们主要用于：

- 同 prompt 候选排序；
- 固定测试集上的平均分变化；
- 大规模初筛，之后由人工校验。

HPS v3、HPS v2、PickScore、ImageReward 的原始值不能互相比较。

## 5. 多模型排名怎么办？

若有 A/B/C/D 四个模型，可先做覆盖均衡的两两比较，再用 Bradley–Terry 拟合相对 rating。必须保留：

- 原始两两胜负矩阵；
- 平局规则；
- 各对有效票数；
- rating 置信区间；
- prompt 和投票人群版本。

Elo/BT 分是相对排名，不是绝对质量分，换 prompt 或对手池可能改变。

## 6. 推荐样本量和分工

一个实用起点：

- 300–500 条私有 prompt；
- 每个关键模型对覆盖同一批 prompt；
- 每对尽量多位独立评审者；
- 自动指标跑 4 seed，人工使用预先固定的 seed；
- 先抽一部分做 pilot，检查题意和一致性，再启动正式标注。

如果预算有限，优先增加独立 prompt 覆盖，而不是让同一批人对同一图重复投票。

## 7. 常见误用

- 给评审者看模型名称或历史排行榜；
- 从多图里挑最好一张参加盲测，却不说明 best-of-N；
- 将 judge VLM 的投票称为“人工胜率”；
- 只报告整体胜率，不看中文文字、人物等关键子集；
- 置信区间跨 50% 仍宣称稳定领先。
