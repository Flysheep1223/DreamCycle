# 知识与推理：WISE / WiScore

## 1. 这个维度测什么？

普通文图对齐可以直接问“图中有没有康乃馨”。但很多真实 prompt 不会把答案直接写出来，例如：

> 画一种人们常在母亲节赠送的花。

模型需要知道答案通常是**康乃馨**，再把它画出来。WISE 用来区分：

1. 模型是否理解隐含的世界知识；
2. 是否把知识答案和关系画正确；
3. 图像是否足够真实、可用，使答案能被验证。

数据有 1,000 条 prompt，覆盖文化常识、时空推理、生物、物理、化学等。

## 2. 原版 WiScore 公式

原版 GPT-4o judge 对三项分别给 0、1、2：

- Consistency：知识答案与关系是否一致；
- Realism：真实可信程度；
- Aesthetic：美学质量。

`WiScore = (0.7×Consistency + 0.2×Realism + 0.1×Aesthetic)/2`

知识一致性权重最大，但总分仍混入了真实感和美学，因此不是纯知识正确率。

## 3. 数值例子：漂亮但知识错误

Prompt：

> 母亲节常送的花，插在透明玻璃花瓶里。

### 图 A：画成玫瑰

假设 judge 给：

- Consistency=0：核心知识答案错误；
- Realism=2：照片感很好；
- Aesthetic=2：构图美观。

`WiScore = (0.7×0 + 0.2×2 + 0.1×2)/2 = 0.30`

### 图 B：画成康乃馨，但画质略普通

- Consistency=2；
- Realism=1；
- Aesthetic=1。

`WiScore = (0.7×2 + 0.2×1 + 0.1×1)/2 = 0.85`

这说明 WiScore 不会仅因 A 更漂亮就掩盖知识错误。若要单独研究知识能力，仍建议另外报告 Consistency 或知识正确率。

> 分数和图像内容均为演示，不是实际 judge 输出。

## 4. 原 prompt 与显式改写对照

分别生成：

1. “母亲节常送的花”；
2. “康乃馨”。

解释方式：

- 原 prompt 很差、显式“康乃馨”很好：更像是**知识理解/提示解析问题**；
- 两者都画不好：更像是**具体花卉视觉生成能力问题**；
- 两者都好：知识和视觉落地都较好。

改写必须保持答案正确，而且要用同一套生成和评分配置。

## 5. WISE_Verified 的不同

2026 年默认维护版改为：

- 约 200 条 prompt 刷新；
- Qwen3.5-35B-A3B 开放 judge；
- 每图二值 0/1；
- 不再分别输出 realism 和 aesthetic。

例如：

- 玫瑰图：知识含义错误，`Score=0`；
- 康乃馨图：知识正确、关系和视觉可用性满足要求，`Score=1`。

**原版 0.85 与 Verified 0/1 不能放在同一列直接比较。**

## 6. 适合加入哪些私有题？

- 节日与文化：“冬至常吃的食物”；
- 物理：“装满水后，哪个杯子重心更低？”——需保证视觉题有明确答案；
- 生物：“完全变态发育昆虫的一个阶段”；
- 时间：“日落前天空呈现的方向性光线”；
- 空间：“从镜子里看，文字应该是什么方向？”

私有题必须配标准解释，并由人工检查是否只有一个合理答案，避免把模糊题当知识错误。

## 7. 常见误用

- judge 自己不知道正确答案，却惩罚生成模型；
- 艺术风格任务中机械奖励照片感；
- 不区分原版和 Verified；
- 只看 Overall，不看 Culture/Time/Space 等分项；
- 把 realism 高当作知识正确。
