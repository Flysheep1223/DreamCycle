# Seedream 全能力评测：三类能力指标方案

> 将 Seedream 的能力压缩为三个分榜：**文生图、指令编辑、参考图与多模态生成**。每类独立评分，不把所有原始分强行相加。
>
> 人评不单独成类，而是在三个分榜中分别用于校准机评和判断整体可用性。

## 一、三类总表

| 类别 | 覆盖能力 | 核心指标 | 可选辅助指标 |
|---|---|---|---|
| **A. 文生图效果** | 通用语义、组合指令、长 Prompt、文字、画质、知识、多样性 | **Soft-TIFA、DPG、OCR、VLM PQ** | VQAScore、WISE、Q-Align、Vendi |
| **B. 指令编辑效果** | 编辑完成度、编辑自然度、未编辑区域保持 | **GEdit SC/PQ/O + 背景 LPIPS/PSNR/SSIM** | Directional CLIP、DINO Structure Distance |
| **C. 参考图与多模态生成** | 单主体保持、多参考/多主体、文本遵循、控制条件 | **DreamBench++ CP/PF + MMIG-AMS** | DINO-I、CLIP-I、VQAScore、主体遗漏/串换率、条件专用指标 |

---

## 二、A 类：文生图效果

### 1. 评什么？

输入只有文本，输出为图像，覆盖：

- 对象、属性、数量、空间关系；
- 长 Prompt 的实体和关系覆盖；
- 中英文、多区域文字；
- 感知画质与美学；
- 知识推理和多 seed 多样性。

### 2. 指标怎么选？

| 子维度 | 主指标 | 评价方式 | 结果怎么理解 |
|---|---|---|---|
| 组合指令 | **Soft-TIFA AM/GM** | VLM 回答固定原子 QA | AM 看平均原子能力；GM 看整 Prompt 联合满足 |
| 长 Prompt | **DPG Overall 与五分项** | VLM 回答依赖图问题 | 重点看 Entity、Attribute、Relation 是否漏项 |
| 文字 | **OCR Accuracy、NED、CER/WER；多区域 OCR-F1** | OCR 专用模型 + 自动计算 | Accuracy 看完全正确；CER 看错漏多字；F1 看多区域完整性 |
| 感知画质 | **固定 VLM PQ rubric 或 Q-Align** | VLM/微调评分模型 | 评价自然度、结构异常、伪影和整体可用性 |
| 知识推理（可选） | **WISE / WiScore** | VLM judge | 检查隐含知识是否画对，Original/Verified 不混用 |
| 多样性（可选） | **组内 Vendi Score** | Embedding + 数学计算 | 必须与语义成功率一起报，避免“坏得各不相同” |

### 3. 一个统一例子

Prompt：

> 咖啡店门口，一位穿红雨衣的女孩推着蓝色自行车，右侧有一只白狗，招牌写“春日咖啡”，写实摄影。

分别检查：

- Soft-TIFA/DPG：人物、雨衣颜色、自行车颜色、狗的位置是否满足；
- OCR：“春日咖啡”是否完全正确；
- PQ：人物和自行车结构是否自然；
- 多 seed：不同结果是否既多样又满足相同要求。

### 4. 本分榜报告格式

```text
组合语义：Soft-TIFA AM / GM
长 Prompt：DPG Overall + Entity / Attribute / Relation
文字：Accuracy / NED / CER / OCR-F1
画质：VLM PQ 或 Q-Align
可选：WISE、Vendi + 多 seed 成功率
```

## 三、B 类：指令编辑效果

### 1. 评什么？

输入为**源图 + 编辑指令**，输出为编辑后图像。必须同时评价：

1. 指定编辑是否完成；
2. 编辑后是否自然；
3. 不该改的区域是否被保持。

只看其中一项都会误判。

### 2. 指标怎么选？

| 子维度 | 主指标 | 评价方式 | 结果怎么理解 |
|---|---|---|---|
| 编辑语义 | **GEdit/VIEScore SC** | 通用 VLM 按系统提示词评分 | 是否完成指令、是否漏改/错改/过度编辑 |
| 编辑画质 | **GEdit/VIEScore PQ** | 通用 VLM 独立评分 | 是否自然、是否有伪影、扭曲和接缝 |
| 单图综合 | **O=√(SC×PQ)** | 程序计算 | SC 或 PQ 很差都会拉低 Overall |
| 背景保持 | **mask 外 LPIPS↓、PSNR↑、SSIM↑** | 传统算法/感知模型 | 检查背景漂移、色偏和纹理重绘 |

### 3. 一个统一例子

指令：

> 给人物增加红宝石项链，其他内容保持不变。

- 加上项链且人物/书店保持：SC、PQ 高，背景误差低；
- 加上项链但换脸换背景：PQ 可高，SC 应低；
- 原图直出：背景保持最好，但编辑 SC 和 Overall 应低。

### 4. 本分榜报告格式

```text
编辑完成：SC + 按编辑类型分项
编辑画质：PQ
综合效果：Overall
背景保持：LPIPS / PSNR / SSIM
```

全局风格、调色等任务不要机械套局部 mask，可改为关键主体、身份和构图保持。

## 四、C 类：参考图与多模态生成

### 1. 评什么？

输入包含**参考图，或参考图 + 文本**，可能有一个或多个主体。核心是两轴：

- 参考主体/概念是否保持；
- 新 Prompt 和组合关系是否完成。

单主体与多主体可以共用这一类，但多主体必须增加遗漏和串换检查。

### 2. 指标怎么选？

| 子维度 | 主指标 | 评价方式 | 结果怎么理解 |
|---|---|---|---|
| 单主体概念保持 | **DreamBench++ CP** | GPT-4o 等 VLM 按 CP rubric 评分 | 形状、颜色、纹理、面部等是否仍是参考概念 |
| 新 Prompt 遵循 | **DreamBench++ PF** | VLM 按 PF rubric 评分 | 新场景、动作、风格是否完成 |
| 多模态细粒度语义 | **MMIG-AMS** | Qwen2.5-VL 回答 aspect QA | 多主体、属性、关系等条件正确比例 |
| 快速主体回归 | **DINO-I、CLIP-I + VQAScore** | Embedding + VLM | 分别近似主体保持和文本遵循，不替代 CP/PF |
| 多主体完整性 | **遗漏率、串换率、全部主体同时正确率** | VLM/检测器 + 程序统计 | 防止一个主体正确掩盖另一个遗漏或串换 |
| 控制条件（按需） | mIoU、mAP、OKS、边缘 F1、深度误差 | 独立专用模型 | 只有输入包含对应控制条件时使用 |

### 3. 一个统一例子

参考图是左耳有黑斑的小狗，目标是：

> 让这只小狗穿宇航服站在月球上。

- 同一只狗且完成场景：CP 高、PF 高；
- 相似品种但身份不同：CP 低、PF 高；
- 直接复制参考图：CP 高、PF 低。

多参考任务，如“特定背包在左、特定运动鞋在右”，还需分别检查两个主体、左右关系和全部主体同时正确率。

### 4. 本分榜报告格式

```text
单主体：CP / PF
多模态：AMS + 各 aspect 分项
快速回归：DINO-I / CLIP-I + VQAScore
多主体：遗漏率 / 串换率 / 全部主体正确率
控制条件：按条件单列专用指标
```

## 五、人评如何嵌入这三类？

只评一个 Seedream 版本时，每类都采用 **1–5 分绝对评分**，不需要强行设置 A/B 对手：

| 分榜 | 人评内容 |
|---|---|
| A. 文生图 | 文图对齐、文字与版式、感知画质、整体可用性 |
| B. 指令编辑 | 编辑完成、背景保持、自然度、整体可用性 |
| C. 参考图与多模态 | 主体身份、文本遵循、多主体完整性、整体可用性 |

不同 Seedream 版本比较时，再在同一类别内做匿名、随机左右的成对胜率。人评子集用于检查 VLM 是否系统性漏掉数量、关系、文字、身份或局部伪影。

## 六、最终只保留三个结果板块

```text
A. 文生图效果
   Soft-TIFA + DPG + OCR + VLM PQ
   可选 WISE / Vendi

B. 指令编辑效果
   GEdit SC / PQ / O
   背景 LPIPS / PSNR / SSIM

C. 参考图与多模态生成
   DreamBench++ CP / PF
   MMIG-AMS + 主体遗漏/串换率
   DINO-I / CLIP-I 作为快速辅助
```

**三分榜已经覆盖全部能力，不需要再把知识、画质、文字、背景保持、多样性等提升为独立大类。** 它们都是对应类别下的子维度。
