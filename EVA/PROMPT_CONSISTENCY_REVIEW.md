# 高难度原题一致性审查与修正

本轮不是单纯增加 Prompt 长度，而是先删除物理矛盾、输入事实错误和左右参照歧义，再复测。

| 案例 | 原题问题 | 修正 |
|---|---|---|
| 时钟车站纸鹤 | 普通镜子中“只能存在现实没有的纸鹤”，物理上无法成立 | 改为现实 6 只实体纸鹤，镜子只反射其中 3 只；全图可见 6 实体＋3 倒影，不允许无实体倒影 |
| 镜面花店 | 左右手未统一人物自身与观众视角；镜子与窗户容易混为同一区域；花瓣可能被误算玫瑰 | 明确人物自身左右及画面位置；镜子位于后墙、窗户位于侧面且相互独立；散落花瓣不计入玫瑰 |
| 纸雕剧场 | 普通镜子显示“不同衣服、还持有现实已不存在的伞”，不是物理反射 | 改为“魔法记忆镜显示过去形象”，与现实宇航服分开；禁止现实形象的倒影混入 |
| 双参考飞艇教室 | 曾要求输入图不存在的浅棕卷发角色；左右手参照不清；窗户易被伞遮挡 | 改为与输入一致的深色短发绿眼少女；明确人物自身左右与画面位置；六扇窗位于人物与伞上方且不得遮挡 |
| 单袖套编辑 | 源图没有“星轨茶馆”和石狐，题面来自另一张图 | 改为保留源图实际“北/春/07”、白猫、黑猫、纸鹤、钟表、书桥、齿轮河与列车，并禁止改成星轨茶馆 |
| 镜面花店编辑 | 只指定“四个花盆”但不指定哪四个；真实新增白猫却不允许自然倒影，普通镜面下矛盾；镜中门牌与真实顶部木牌混淆 | 改为镜中原“07”门牌原位替换；真实镜框两侧放纸鹤；四个真实位置明确为“新增花盆”；允许自然倒影但不计为真实白猫，禁止无实体对应的镜中白猫 |
| 纸雕剧场服装 | “藏青和服外套”与参考角色原始服装不一致 | 改为恢复参考图原始外套、内搭、下装与透明伞，不自行指定和服 |
| 单袖套编辑 | 源图中目标电子袖套不清晰，模型改错了其他角色 | 改为清晰可见的右侧红色蝴蝶结发饰，只改颜色，禁止改其他角色袖章 |
| 时钟车站文字 | “不要其他店名”无法判断日历数字是否违规 | 明确除北/春/07外，任何可读文字、数字、页码和编号都禁止 |

## 任务4左右手机评复测结果

对同一张双参考生成图，固定“人物自身左手扳手、右手红书＋画面位置锚点”的检查项，共进行 12 次总尝试：

- 8 次返回可解析评分；
- 右手红书误判 **6/8 = 75%**；
- 左手扳手误判 **0/8 = 0%**；
- 任意手部误判 **6/8 = 75%**；
- 另有 **4/12 = 33.3%** 的理由反复改口、JSON 截断等协议失败。

这表明当前 VLM 对该左右手任务有系统性误判倾向，不能仅根据单次失败标签下结论。修正方式是将“人物自身左右＋画面位置”写入原题与评审问题，并分别判断两只手；评审器也需要限制理由长度并允许 JSON 失败重试。该比例只代表这张图的重复实验，不能外推为所有任务的统一错误率。

## 复测原则

1. 原图和原始错误结果保留，不修改历史分数。
2. 修正 Prompt 后重新生成，不只重跑评分。
3. 继续输出分离的 Task、Preservation、PQ、CP/PF、OCR、逐项检查和全项通过率，不计算总分。
4. 对左右手等机评易错点，使用固定检查项重复评审，单独统计误判率。
5. 机评结论仍需与图片证据对照，不能把失败标签当作绝对真值。
