# 评测问题修正记录：图片与分离验证结果

本文记录高难度样例与 Prompt Advisor 暴露的问题。旧图片和旧结果保留，修正后均在新目录重新评分，不篡改历史结果。

> 当前实现只输出分离指标，不再计算 Overall、Strict Overall、权重或跨指标归一化分。下面展示的是各指标原始值，而不是总分变化。

## 已修正的问题

| 问题 | 修正方式 | 代码位置 |
|---|---|---|
| OCR 检出目标文字就给文字高分 | 独立报告 `text_layout_score`，检查载体、位置、重复和指定排版关系 | `judge/`、`scoring/` |
| 额外文字与正常补充说明混为一谈 | 使用 `no_extra_text` 标记明确的全画面文字限制，但不把 OCR 与布局分合成总分 | `router/`、`scoring/` |
| 镜中倒影被误判为现实新增人物 | 路由和评审显式区分现实实体与倒影，倒影内容独立检查 | `router/prompts.py`、`judge/prompts.py` |
| 源图不存在的对象仍按普通生成失败计分 | 新增 `input_warnings`，提前报告不可能的删除/保留与错误数量前提 | `schemas/`、`router/`、`scoring/` |
| 首次评审漏答检查项导致整例失败 | 自动纠偏重试一次，两次失败才中止，并保存所有原始尝试 | `judge/` |
| 算术平均掩盖关键失败 | 不再合成总分；单独报告逐项检查、全项通过率和最低检查项 | `scoring/` |
| 测试 Prompt 与源图不一致 | 修正高难度脚本中的镜面花店编辑题，并增加源图事实检查 | `examples/run_hard_showcase.py` |

## 真实复核 1：镜面花店

![镜面花店原图：两名现实人物、镜中背影、重复 LEFT 价签和镜面街景](runs/run-20261115T112951-e6f3d43a/generated-00.png)

### 修正后的分离结果

- 动态 VQA：以逐项任务检查为准；
- PQ：7.0/10；
- OCR Accuracy：1.0；
- 文字布局分：0.4；
- 全项通过率：47.62%。

### 现在能够正确区分

- 镜中两人背影不直接算作额外实体人物；
- 重复 LEFT 价签属于额外/重复文字；
- 镜面街景、左右手、遮挡和玫瑰数量分别扣分；
- 少女左手没有正确握住蓝水壶，且水壶悬浮；
- 窗外街道和车辆位置、数量不符合要求。

### 新评审提示词的关键变化

```text
现实空间人物与镜中/玻璃倒影必须分开。
倒影不算额外实体人物，但倒影是否被错误增加、删除、换脸、换衣服或改变动作，
必须在对应检查项中单独判断。
```

![六人时钟车站原图：多层结构、纸鹤、角色和指定文字](runs/run-20261115T112951-3fa515a7/generated-00.png)

### 修正后的分离结果

- 全项通过率：85.19%；
- 文字布局分：0.75；
- 主要问题维度：文字位置、额外文字、纸鹤数量及倒影对应关系。

### 新增或加强的检查

- 额外店名与其他违规文字；
- “春”的载体和位置，以及其他位置的重复“春”；
- 现实纸鹤、镜面专属纸鹤和现实纸鹤倒影的区别；
- 两辆列车的车头是否明确朝向相反方向；
- 角色、猫、狐狸及道具是否发生错配。

> 两次评审使用了不同动态检查清单，VLM 本身也有波动，所以不应把指标变化当作纯代码消融实验。这里主要验证的是：旧协议漏掉的错误不再被 OCR 命中和倒影规则掩盖。

## 真实复核 3：源图事实警告

对以下错误前提执行路由：

> 源图有五只白猫，删除一只变为四只；删除三艘飞艇；保留彩虹鲸鱼和“云上书店”招牌。

实际返回的 `input_warnings` 为：

```text
输入原图中未观察到任何白猫，用户声称原图白猫总数为五只的描述与源图事实不符。
输入原图中未观察到远处的三艘小飞艇，用户要求删除三艘小飞艇的前提与源图事实不符。
输入原图中未观察到彩虹鲸鱼，用户要求保留彩虹鲸鱼的前提与源图事实不符。
输入原图中未观察到入口招牌及“云上书店”文字，用户要求保留该文字的前提与源图事实不符。
```

这样可以在评分前区分：

1. 测试题本身错误；
2. 源图事实缺失；
3. 真正的生成失败。

## 当前分离输出示例

```json
{
  "task_score": 0.875,
  "preservation_score": 1.0,
  "text_layout_score": 1.0,
  "perceptual_quality": 8.0,
  "reference": {"cp": 4.0, "pf": 3.0},
  "ocr": {
    "accuracy": 1.0,
    "ned": 1.0,
    "cer": 0.0,
    "f1": 1.0
  },
  "full_requirement_rate": 0.9048,
  "minimum_requirement_score": 0.0
}
```

这些字段不再被合成为单一分数。OCR Accuracy 高不代表文字位置正确，动态 VQA 高不代表保持度好，PQ 高也不代表指令完成。
